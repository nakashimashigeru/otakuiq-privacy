プライバシーポリシー

最終更新日: 2026年9月27日

OshiQ（以下「本アプリ」）は、ユーザーのプライバシーを尊重し、個人情報の保護に努めます。本ポリシーでは、本アプリが収集・利用するデータについて説明します。

1. 収集するデータ

(a) 端末内に保存するデータ

  • お気に入りの VTuber チャンネル ID リスト
  • 視聴済み配信の履歴（30 日で自動削除）
  • アプリ設定（言語）

これらのデータは端末のローカルストレージ（SharedPreferences）に保存されます。

(b) Firebase Auth / Firestore / Cloud Functions

本アプリは Google Firebase を利用します。

  • 匿名認証で発行される Firebase UID（個人を特定しないランダムな識別子）
  • お気に入り VTuber と視聴履歴のクラウド同期（同一 Google アカウント内でのデータ引き継ぎ用）

これらのデータは個人を特定するものではなく、複数端末間のデータ同期にのみ使用します。

(c) Firebase Analytics / Crashlytics / Cloud Messaging

本アプリは以下のデータを匿名で収集します。

  • アプリの利用状況（画面遷移、機能利用イベント）
  • クラッシュレポート（エラー発生時のスタックトレース）
  • 端末情報（OS バージョン、端末モデル、言語設定）
  • プッシュ通知の配信トークン（未視聴ダイジェスト通知の送信にのみ使用）

これらのデータは個人を特定するものではなく、アプリの改善と通知配信の目的でのみ使用します。

(d) YouTube API サービス

本アプリは VTuber の配信情報の取得に YouTube API サービスを利用します。取得は本アプリのサーバー側で行われ、ユーザーの個人情報が YouTube に送信されることはありません。YouTube API サービスの利用には Google のプライバシーポリシーが適用されます。

2. データの第三者提供

本アプリは、Firebase 各種サービス、YouTube API サービスを通じて Google LLC にデータを送信します。それ以外の第三者にユーザーデータを提供・販売することはありません。

3. データの保持と削除

端末内のデータは、アプリをアンインストールすると全て削除されます。クラウド同期データについては、お問い合わせいただければ削除いたします。

4. お子様のプライバシー

本アプリは13歳未満のお子様を対象としていません。13歳未満の方から意図的に個人情報を収集することはありません。

5. 本ポリシーの変更

本ポリシーは予告なく変更される場合があります。重要な変更がある場合は、アプリ内で通知します。

6. お問い合わせ

本ポリシーに関するご質問は、以下までお問い合わせください。

Privacy Policy

Last updated: September 27, 2026

OshiQ ("the App") respects your privacy and is committed to protecting your personal information. This policy describes the data the App collects and how it is used.

1. Data We Collect

(a) Data stored on your device

  • List of favorite VTuber channel IDs
  • Watch history for streams (automatically deleted after 30 days)
  • App settings (language)

This data is stored in your device's local storage (SharedPreferences).

(b) Firebase Auth / Firestore / Cloud Functions

The App uses Google Firebase for:

  • Anonymous authentication (a random Firebase UID that does not identify you)
  • Cross-device sync of your oshi list and watch history within the same Google account

This data does not personally identify you and is used solely for cross-device sync.

(c) Firebase Analytics / Crashlytics / Cloud Messaging

The App anonymously collects:

  • App usage data (screen transitions, feature usage events)
  • Crash reports (stack traces when errors occur)
  • Device information (OS version, device model, language settings)
  • Push notification delivery tokens (used solely to deliver the unwatched digest notification)

This data does not personally identify you and is used solely to improve the App and deliver notifications.

(d) YouTube API Services

The App uses YouTube API Services to fetch VTuber stream information. Requests are made server-side by the App's backend, and none of your personal information is ever sent to YouTube. Use of YouTube API Services is subject to the Google Privacy Policy.

2. Third-Party Sharing

The App transmits data to Google LLC through Firebase services and YouTube API Services. We do not provide or sell user data to any other third parties.

3. Data Retention and Deletion

Uninstalling the App removes all local data from your device. To delete cloud-synced data, please contact us.

4. Children's Privacy

The App is not intended for children under 13. We do not knowingly collect personal information from children under 13.

5. Changes to This Policy

This policy may be updated without prior notice. We will notify you within the App of any significant changes.

6. Contact

If you have questions about this policy, please contact us at:
lixiaolong.dev@gmail.com

Kebijakan Privasi

Terakhir diperbarui: 27 September 2026

OshiQ ("Aplikasi") menghormati privasi Anda dan berkomitmen untuk melindungi informasi pribadi Anda. Kebijakan ini menjelaskan data yang dikumpulkan dan digunakan oleh Aplikasi.

1. Data yang Kami Kumpulkan

(a) Data yang disimpan di perangkat Anda

  • Daftar ID channel VTuber favorit
  • Riwayat siaran yang sudah ditonton (dihapus otomatis setelah 30 hari)
  • Pengaturan aplikasi (bahasa)

Data ini disimpan di penyimpanan lokal perangkat Anda (SharedPreferences).

(b) Firebase Auth / Firestore / Cloud Functions

Aplikasi menggunakan Google Firebase untuk:

  • Autentikasi anonim (Firebase UID acak yang tidak mengidentifikasi Anda)
  • Sinkronisasi daftar oshi dan riwayat tonton lintas perangkat pada akun Google yang sama

Data ini tidak mengidentifikasi Anda secara pribadi dan hanya digunakan untuk sinkronisasi data.

(c) Firebase Analytics / Crashlytics / Cloud Messaging

Aplikasi mengumpulkan data anonim:

  • Data penggunaan aplikasi (transisi layar, event penggunaan fitur)
  • Laporan crash (stack trace saat error)
  • Informasi perangkat (versi OS, model perangkat, pengaturan bahasa)
  • Token pengiriman notifikasi push (hanya digunakan untuk notifikasi ringkasan belum ditonton)

Data ini tidak mengidentifikasi Anda dan hanya digunakan untuk meningkatkan Aplikasi dan mengirim notifikasi.

(d) Layanan YouTube API

Aplikasi menggunakan layanan YouTube API untuk mendapatkan informasi siaran VTuber. Pengambilan dilakukan di sisi server Aplikasi, dan informasi pribadi Anda tidak pernah dikirim ke YouTube. Penggunaan layanan YouTube API tunduk pada Kebijakan Privasi Google.

2. Berbagi dengan Pihak Ketiga

Aplikasi mengirim data ke Google LLC melalui layanan Firebase dan layanan YouTube API. Kami tidak menyediakan atau menjual data pengguna kepada pihak ketiga lainnya.

3. Penyimpanan dan Penghapusan Data

Menghapus Aplikasi akan menghapus semua data lokal dari perangkat Anda. Untuk menghapus data yang tersinkronisasi di cloud, silakan hubungi kami.

4. Privasi Anak

Aplikasi ini tidak ditujukan untuk anak di bawah 13 tahun. Kami tidak secara sengaja mengumpulkan informasi pribadi dari anak di bawah 13 tahun.

5. Perubahan Kebijakan Ini

Kebijakan ini dapat diperbarui tanpa pemberitahuan sebelumnya. Kami akan memberi tahu Anda di dalam Aplikasi tentang perubahan signifikan.
